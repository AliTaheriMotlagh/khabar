# khabar — Persian news site from the @dlmehr Telegram channel

Primary site: https://blog.remixt.app (canonical, Cloudflare Pages Free: `wrangler.toml`, `functions/` runs the same `api/router.js` and keeps `s-maxage` answers in Cloudflare's cache (`functions/_router.js cached`: Pages doesn't cache Functions by itself), `public/_headers`, `public/_routes.json` (Functions only on `/api/*`, `/rss/top.xml`, `/ads.txt`); deployed by `scripts/publish.sh` inside site.yml's build job). Free-plan limits that bite: 20,000 files per deployment (`publish.sh` warns at 18,000 — every new page type per story costs ~2,000 files), 100K Function requests/day. GitHub Pages builds a mirror; the old Vercel deployment (khabar-ai.vercel.app) is disabled (402) — nothing should call it. Channel owner: Mehrzad Samadi (https://mehrzad.ai/).

## How it fits together
- `pipeline/` (Python, httpx + bs4): crawls `t.me/s/dlmehr`, takes **Gholam's first comment** (the Persian translation, posted by a bot named «غلام», signed «داش غلام»; his code, https://github.com/mehrzads/gholam, is older than what he posts — the channel is the reference) from the post's discussion widget; a new post without it yet is held off the site `GHOLAM_HOLD_MINUTES` (10, `run.awaits_gholam`; not digests or bare YouTube shares), so it's never published or pushed as its English source; reads linked tweets (api.fxtwitter.com) / pages, writes `data/posts/<id>.json`. Media is **never downloaded** — posts keep original URLs (Telegram CDN URLs are signed, refreshed on every crawl).
- `src/` (Astro 7, static): `lib/posts.ts` shapes raw posts (`kind`: story | digest | brief; English digests are hidden). Components in `src/components/`, pages in `src/pages/`, one stylesheet `src/styles/global.css` (tokens at the top, light/dark).
- `src/lib/source.ts` (no imports, `tests/source.test.mjs`): sources in any language — `publisherOf` (domain → name, incl. publishers' short links), `langOf` (script, then common words), `cleanUrl` (tracking params; X/YouTube-specific ones only there), `shortUrl`, `citedLinks` (a tweet's article), `translateUrl`, `isShortener`. Used by `SourceCard`/`SourceChip`.
- Covers: `posts.ts` never takes a profile picture or logo (`AVATAR`/`notAPicture`) nor an X/FxTwitter link preview's picture (always the author's avatar; `avatarPreview`, `preview.small` from `telegram.py` for Telegram's side picture) — `tests/site.test.mjs` checks recent.json.
- `src/lib/align.ts`: word timings from a spoken clip's sound (weights fitted on the site's voices, pinned to the pauses after sentences/commas, snapped to near-silences) — no imports, `tests/align.test.mjs`.
- `pipeline/ai.py`: a headline, a short line and a type («خبر», «ابزار و محصول», «پژوهش و مقاله»…) per story by Qwen3.5-9B — llama.cpp's `llama-server` on the runner (`scripts/ai-server.sh`: pinned + SHA-256-checked, the model in the Actions cache keyed on that file's hash; also runs on a Mac). JSON-schema answers, checked (`problems`: length, Persian, no colloquial words), retried once, else `{"failed": true}`; stored as `post.ai` with `src` (input hash) and `v` (`PROMPT_V`: bump it when the prompt changes, every post is redone). The crawl keeps `ai` across re-saves. The site uses `ai.title`/`ai.short`/`ai.type`, and `ai.topics` from `PROMPT_V` 2 on (`topicsOf` in posts.ts): each topic is kept only when the text names it (`ai.grounded` → `shape.named`; v1's invented آنتروپیک/کسب‌وکار everywhere), else the keyword rules' (golden set: precision 76% vs 72%, section 29/39 vs 25/39). **Gholam's text is always the story** (minus his greeting); the model only writes around it (headline, short, type, topics, extras, spoken names) or translates when he never commented (`ai.story`). Don't touch `scripts/ai-server.sh` for comments: its hash is the model cache's key (a 5.7 GB download). `--eval` scores `pipeline/tests/golden.json` (`ai-eval.yml` runs it on the runner); `ai-backfill.yml` does posts older than 3 days; `/ai.json` → /admin/.
- `pipeline/videos.py` → `data/videos.json`: Mehrzad's YouTube channel (@mehrzad.samadi) from his posts + yt-dlp (daily, or when a post shares an unknown video; runner only — the dev machine can't reach YouTube) + the channel's RSS as fallback. Site: `src/lib/videos.ts`, `/videos/`, `/videos/<id>/` (no embed; Gholam's summary, chapters → YouTube `&t=`), `NewVideo.astro` on the home page for 48 h, a red circle in front of the rail for 7 days (grey once opened, `video-seen`), `rss/videos.xml`; push kind `video` reaches every mode. A post that only shares a YouTube video is listed without Gholam (`sharedVideo` in posts.ts).
- **English edition** `/en/` (`src/lib/en.ts`, `src/pages/en/`, `EnCard`/`EnTimeline`): the source's own text (tweet, linked article, quoted post — never Gholam), headline = `ai.en.title` (`pipeline/ai_en.py`, EN_V) → a newsroom's/maker's article title → the source's first sentence; posts without English source text have no English page. `Base.astro` takes `lang` + `alternates` (hreflang pairs, og:locale, the header's language switch `[data-lang-switch]`, remembered in `lang`; only the Persian home redirects a reader who chose English). English pages skip Pagefind (file budget): their search is the explorer (`/en/search/` forwards there). Twins also: feeds (`src/lib/en-feed.ts`: en/rss.xml, en/rss/daily.xml, en/rss/videos.xml, en/topic/<slug>/rss.xml), calendar (+ en/calendar.ics), models, who (index → explorer, no page per name), today (list + «Listen to all», device voice), week, stats, saved, offline, 404 (moved to en/404.html by astro.config's `en-404`), videos/<id>; each Persian twin passes `alternates.en` and the sitemap's `twin` regex lists them. ## Gotchas
- The site tests run on every crawl's data and gate the Pages mirror (notify runs anyway). Data from outside can break them: `feedPicture` never puts an address on a filtered CDN it can't relay into a feed, and X's login-wall pages (generic `abs.twimg.com` picture, «X - The Everything App») and YouTube's crawler walls («- YouTube», «Before you continue») are never a picture or a title (`posts.ts` `PLACEHOLDER`, `shape.WALL_TITLE`).
- Readers are mostly in Iran: Telegram/X CDNs and t.me are filtered, and a browser's multiplexed connection to other foreign hosts stalls (wsrv.nl/Cloudflare: 9 parallel requests on one HTTP/2 connection → nothing; the site's Vercel domain → fine). So images come through the site first: `picture()`/`pic()` in `src/lib/posts.ts` give `src` + `data-alt` = [/api/img relay, wsrv.nl, original, fresh]. Social cards and JSON-LD keep original URLs; The feeds (`src/lib/feed.ts`: `rss.xml` every post, `rss/news.xml`, `rss/daily.xml`, `tag/<tag>/rss.xml`; the newest 100 whole, older ones headline + summary; cover as `media:thumbnail`, never `<enclosure>` — readers would show it twice; listed on `/feeds/`) use `feedPicture()` = the relay on the primary domain (readers keep items for good, and Telegram URLs expire), checked by `tests/site.test.mjs`.
- `data-fresh` is the «خبرهای تازه رسید» pill (social.ts binds a reload to every `[data-fresh]`): media use `data-alt`.
- The on-device voice: iOS audio must start in the tap — `Speaker` plays 50 ms of silence in it, then the clips. The worker is terminated on `pagehide` (Safari's back cache would keep its ~550 MB alive). Private browsing keeps no Cache Storage across pages (the sheet says so). `public/sw.js` must keep `voice-v1`.
- Telegram comment HTML has a hidden reply template with a *truncated* copy of the text — always read `.js-message_text` (see `telegram._own_text`).
- X video CDN returns 403 with a foreign Referer → site-wide `<meta name="referrer" content="no-referrer">`; outbound links to t.me/mehrzad.ai use `referrerpolicy="origin"`.
- `post.cover` is always a still image (video → poster); use `sized()` for pbs.twimg.com sizes.
- iOS has no Persian TTS voice, and only starts audio inside a tap: `Speaker.start()`/`resume()` must not await before playing.
- Safari sizes a height-less column flexbox from `flex-basis`: `flex: 1` (basis 0%) collapses it — use `flex: 1 1 auto` (see `.peek-scroll`).
- `data-today` / `data-total` / `data-online` are filled by `social.ts` with live counts site-wide: don't reuse those attribute names for anything else.
- Upstash free tier is ~500K commands/month: keep API calls batched (`engage` = one pipeline per page) and CDN-cacheable.
